# 八卦运势

基于用户提供的 `八卦运势.html` 创建的独立 GitHub Pages 项目。

## 部署设置

1. 打开仓库 **Settings → Pages**。
2. 在 **Build and deployment** 中选择 **Deploy from a branch**。
3. Branch 选择 `main`，目录选择 `/(root)`，点击 **Save**。
4. 等待部署完成后，访问： https://aplusachiever3.github.io/bagua-yunshi/

## 说明

- `index.html` 是 GitHub Pages 默认入口文件。
- 起卦内容属于传统文化娱乐，不构成专业决策建议。
